# mlx-node

Node.js bindings for [MLX](https://github.com/ml-explore/mlx) - Apple's array framework for machine learning on Apple Silicon.

## Installation

```bash
npm install mlx-node
```

**Requirements:**
- macOS with Apple Silicon (M1/M2/M3/M4)
- Node.js 18+

## Usage

```javascript
import mlx from 'mlx-node';

// Create arrays
const a = mlx.array([1, 2, 3, 4]);
const b = mlx.array([5, 6, 7, 8]);

// Operations
const c = mlx.add(a, b);
console.log(c.tolist()); // [6, 8, 10, 12]

// Matrix operations
const matrix = mlx.array([[1, 2], [3, 4]]);
console.log(matrix.shape); // [2, 2]
console.log(matrix.dtype); // 'float32'

// Reductions
const total = mlx.sum(matrix);
const colMeans = mlx.mean(matrix, 0);
```

## API

### Array Creation

```javascript
mlx.zeros([3, 3])           // 3x3 zeros
mlx.ones([2, 4])            // 2x4 ones
mlx.full([2, 2], 7)         // 2x2 filled with 7
mlx.arange(0, 10, 2)        // [0, 2, 4, 6, 8]
mlx.linspace(0, 1, 5)       // [0, 0.25, 0.5, 0.75, 1]
mlx.eye(3)                  // 3x3 identity
```

### Math Operations

```javascript
mlx.add(a, b)
mlx.subtract(a, b)
mlx.multiply(a, b)
mlx.divide(a, b)
mlx.matmul(a, b)
mlx.sqrt(a)
mlx.exp(a)
mlx.log(a)
```

### Reductions

```javascript
mlx.sum(a)              // Sum all elements
mlx.sum(a, 0)           // Sum along axis 0
mlx.sum(a, [0, 1])      // Sum along multiple axes
mlx.mean(a)
mlx.max(a)
mlx.min(a)
mlx.prod(a)
mlx.var(a)
mlx.std(a)
```

### Array Properties

```javascript
const arr = mlx.array([[1, 2, 3], [4, 5, 6]]);
arr.shape      // [2, 3]
arr.ndim       // 2
arr.size       // 6
arr.dtype      // 'float32'
arr.itemsize   // 4
arr.nbytes     // 24
arr.tolist()   // [[1, 2, 3], [4, 5, 6]]
arr.item()     // Get scalar value (for 0-d arrays)
```

### Data Types

```javascript
mlx.bool
mlx.uint8, mlx.uint16, mlx.uint32, mlx.uint64
mlx.int8, mlx.int16, mlx.int32, mlx.int64
mlx.float16, mlx.float32, mlx.float64
mlx.bfloat16
mlx.complex64
```

## Building

```bash
# Build native addon
npm run build

# Rebuild after changes
npm run rebuild

# Clean build artifacts
npm run clean
```

## Generated Files

This package uses pre-generated bindings committed to the repository:

| File | Purpose |
|------|---------|
| `generated/binding.cpp` | N-API C++ wrapper code |
| `generated/.bindings-hash` | Hash for freshness checking |

These files are generated by `@mlx-node/codegen` and rarely need regeneration.
